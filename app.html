📱 앱 사용법

🤖
Android (크롬)
앱 설치 후 사용
ℹ️ 안드로이드 크롬은 웹앱을 "연결 프로그램" 목록에 등록하는 기능을 지원하지 않아요. 아래 방법으로 사용하세요.
1
앱 설치 (홈 화면에 추가) 화면 하단 앱으로 설치하기 배너를 탭하거나, 크롬 메뉴(⋮) → 앱 설치를 선택하세요.
2
홈 화면 아이콘으로 앱 실행 홈 화면의 PDF뷰어 아이콘을 탭해서 앱을 열어주세요.
3
파일 선택으로 PDF 열기 앱 내 파일 선택 버튼을 탭 → 파일 앱에서 원하는 PDF를 선택하면 바로 열립니다.
4
카카오톡·메일 등에서 받은 PDF 파일을 다운로드 후, 앱에서 파일 선택으로 내 파일 → 다운로드 폴더에서 열면 됩니다.
🍎
iPhone / iPad (사파리)
부분 지원
1
홈 화면에 추가 사파리에서 이 페이지를 열고, 하단 공유 버튼(□↑) → 홈 화면에 추가를 탭하세요.
2
홈 화면 아이콘으로 실행 홈 화면의 PDF뷰어 아이콘을 탭하면 앱처럼 실행됩니다.
3
PDF 열기 앱 실행 후 파일 선택 버튼으로 PDF를 선택하거나, 메일/메시지에서 PDF를 길게 눌러 공유 → PDF뷰어로 열 수 있습니다.
⚠️ iOS Safari는 파일 기본 앱 지정을 지원하지 않아요. PDF를 탭할 때마다 앱을 직접 선택해야 합니다.
💻
Windows PC (크롬 / 엣지)
완전 지원
ℹ️ PWA 앱은 Windows 기본 앱 설정 목록에 나타나지 않아요. 아래 우클릭 방법으로 설정하세요.
1
앱 설치 (선행 필수) 크롬/엣지로 이 사이트 방문 후, 주소창 우측 설치 아이콘(⊕) 클릭 또는 메뉴(⋮) → 앱으로 설치를 선택하세요.
2
PDF 파일 우클릭 파일 탐색기에서 PDF 파일을 우클릭 → 연결 프로그램 → 다른 앱 선택을 눌러요.
3
앱 선택 후 기본 설정 목록에서 광고 없는 PDF 뷰어를 선택하고 항상 이 앱 사용에 체크 후 확인. 이후 PDF를 더블클릭하면 자동으로 열려요.
